# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about records factual. Do not post private information about anyone. Harassment, discriminatory language and personal attacks are not tolerated.

**Reporting.** Report unacceptable behavior privately to the maintainer through the contact method listed on the maintainer's GitHub profile, or by opening a confidential security advisory if the matter is sensitive. Reports are handled confidentially. The maintainer may remove comments, close issues or block participants who violate this code.
